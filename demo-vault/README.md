# Bases Auto Row Height demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Bases Auto Row Height](https://github.com/mnaoumov/obsidian-bases-auto-row-height) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **`Bases Auto Row Height`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `bases-auto-row-height-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-bases-auto-row-height/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `bases-auto-row-height-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
